# Security Policy

This repository is a static collection of learning and productivity links. It has no server-side application, account system, form processing, or repository-managed runtime dependencies.

## Safe use

- External links navigate to third-party services; review their destinations and privacy practices independently.
- Do not add passwords, access tokens, private documents, or personal information to the page or repository.
- Keep third-party URLs current and remove links that become suspicious or are no longer intended.
- Review any future JavaScript, analytics, forms, or embedded content before adding it; the current site should remain a simple static page.

## Reporting

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting feature when available. Do not include private account details in public issues.
