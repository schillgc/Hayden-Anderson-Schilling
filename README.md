# Hayden's Learning Links

A small, static page that brings together frequently used learning and productivity resources.

## Resources

- [Google](https://www.google.com/)
- [Microsoft Word](https://office.live.com/start/Word.aspx)
- [Microsoft PowerPoint](https://office.live.com/start/PowerPoint.aspx)

## Local preview

Open `index.html` directly in a browser. The page uses only HTML and CSS, contains no JavaScript, and does not require a build step or runtime dependencies. A restrictive content-security policy permits only same-origin stylesheet and image resources.

## Deployment

This repository is configured for GitHub Pages. The site is served from the repository's published branch/folder configuration in GitHub.
